Portfolio Case Study & Executive Brief

Earscure / Mir's Core B2B Financial Engineering Project

Executive Summary

This dashboard models the complete B2B wholesale revenue performance and financial reconciliation operations for Earscure / Mir's Core (Luxury Abaya & Apparel Wholesaling). It replaces fragmented WhatsApp order spreadsheets with a unified SQL data pipeline and clean Power BI presentation canvas.

Core Business Problem

  • Raw wholesale orders submitted through unstandardized manual chats and spreadsheets.
  • Reconciliation delays averaging 6.8 days per audit period.
  • Lack of real-time visibility into export market margins (GCC, Europe, North America).

Data Engineering & Solution Architecture

  • SQL data cleaning routines created a standardized star-schema data model.
  • Power BI / Excel DAX measures calculated automated variance vs budget targets.
  • Automated reconciliation rules achieved 99.64% invoice matching accuracy.

Quantifiable Results

  • 38% Reduction in Turnaround Time: Slashed order verification from 6.8 to 4.2 days.
  • +$37.5K Favorable Budget Variance: Real-time tracking helped optimize high-margin categories.
  • 14.5 Hours/Week Saved: Fully automated reporting eliminated manual copy-paste spreadsheet tasks.
